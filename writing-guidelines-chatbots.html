Writing Guidelines

Conversational
Chatbot Writing

Internal guidelines authored at a global hearing care brand to standardise chatbot copy across digital products. These principles cover tone, message structure, error handling, and interaction patterns for regulated, support-focused contexts.

Core Principles

What is important

Seven principles that every chatbot message should be measured against — from task clarity and tone to graceful failure handling.

01
Task-first communication
Every message should help the user move forward. Make it immediately clear: what the bot can do, and what the user should do next.
Correct"Please choose one of the options below."
Avoid"What would you like to do today?"
02
Clear, concise messages
Keep messages short and focused. One instruction or question per turn. Use simple sentence structures.
Correct"Enter your email address."
Avoid"Could you please provide the email address you used when signing up?"
03
Predictable conversation patterns
Use consistent wording for confirmations, errors, and retries. Reuse patterns so users learn how the bot works.
CorrectAlways: "Try again"
AvoidMixing: "Retry", "Give it another shot", "Please reattempt"
04
Turn-based interaction
Ask for one input at a time. Wait for the user before continuing. Break complex flows into steps.
Correct"Enter your date of birth."
→ user responds
"Thank you. Now enter your postal code."
AvoidAsking for multiple pieces of data in a single message.
05
Clear system status and transparency
Tell users what the bot is doing. Set realistic expectations rather than leaving them waiting in silence.
Correct"I'm checking your request. This may take a few seconds."
Avoid"Processing…"
06
Calm, neutral tone
Friendly but professional. Supportive, not playful or emotional. Especially important in support or regulated contexts.
Correct"I couldn't find that information."
Avoid"Oops! That didn't work 😅"
07
Graceful error handling
Always explain what went wrong and what the user can do next. Never leave someone stuck without a path forward.
Correct"I didn't understand that. Please choose one of the options below."
AvoidGeneric failure messages with no next step.
Anti-Patterns

What to avoid

Common mistakes that erode trust, confuse users, or create friction in conversational flows.

01
Long or dense messages
No paragraphs, no information dumps. Break content into steps users can act on one at a time.
✗ "Here's everything you need to know about your account…" ✓ Break into steps
02
Vague or generic responses
Avoid messages that don't help users recover. Every error should name the problem and the solution.
✗ "Something went wrong." ✓ "The file format is not supported. Upload a PDF or PNG."
03
Overpersonalisation or strong personality
Avoid jokes, emojis (unless intentionally designed), and slang. The bot's job is to help, not entertain.
✗ "Heyyyy! Let's fix this together 😄" ✓ "Let's fix this."
04
Asking multiple questions at once
Each turn should request exactly one piece of information. Compound questions create cognitive overload.
✗ "Enter your name, email, and phone number." ✓ Ask sequentially
05
Blaming the user
Never imply user fault. Frame all errors as system observations, not user mistakes.
✗ "You entered an invalid value." ✓ "The value entered is not valid."
06
Pretending to be human
Be transparent that the user is interacting with a system. Trust erodes quickly when the illusion breaks.
✗ "I'll personally take care of this." ✓ "I can help guide you through this."
